How it works

Four steps, all mechanical. The point is that taste is encoded as rules, so the output is defensible — every number can be checked.

01

Match

Pick a register — calm, vivid, elegant, dark — and the engine selects from an evidence library of curated palettes.

02

Derive

Five colors become a working system: surface, ink, accents and weak text levels, derived in OKLCH for perceptual evenness.

03

Gate

Contrast (WCAG + APCA), three color-blind simulations, an AI-slop signature check and a five-axis score. Failures are named, not guessed.

04

Emit

CSS custom properties, SVG slot lists, scene renderings or an image-generation prompt block — ready to paste into real work.
